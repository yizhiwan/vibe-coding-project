# vibe-coding-project

This will be main root directory. There will be multiple different projects in this repository.

## Projects

| # | Project | What it is | Built with |
| --- | --- | --- | --- |
| 1 | [alphabet-adventure](alphabet-adventure) | HTML web based game for kids to learn the alphabet in interactive ways: hear, trace and find objects for each letter | HTML, CSS, JavaScript |
| 2 | [telegram-career-coach](telegram-career-coach) | Serverless Telegram bot that checks portfolio uptime, rewrites resume bullets, and runs a 10-question mock interview with STAR feedback | Python, Google Cloud Functions |
| 3 | [number-ninja](number-ninja) | Maths game for kids: count, add, take away and slice numbers to earn ninja belts | HTML, CSS, JavaScript |
| 4 | TBC | | |

## Running the projects

**alphabet-adventure** and **number-ninja** — open the folder's `index.html` in a browser. For a live-reloading dev server on port 3000:

```bash
cd number-ninja && npm install && npm run dev
```

(swap `number-ninja` for `alphabet-adventure` to run the other game)

**telegram-career-coach** — see [telegram-career-coach/README.md](telegram-career-coach/README.md) for commands, deployment to Google Cloud and local testing.
